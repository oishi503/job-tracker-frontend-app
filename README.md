# Job Tracker - Frontend

React frontend for the Job Application Tracker app.

## Tech Stack
- React.js
- Axios
- React Router DOM

## Features
- Login and Signup
- Add, update, delete job applications
- Filter by status (Applied, Interview, Offer, Rejected)
